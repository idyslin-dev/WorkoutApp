# Calisthenics

A Progressive Web App (PWA) for a calisthenics workout program, made for iPhone.

## Run locally
```
python3 -m http.server 8080
```
Open http://localhost:8080.

## Install on iPhone
Host the folder somewhere served over HTTPS (for example GitHub Pages or Netlify), open the URL in Safari,
then tap Share → Add to Home Screen. The app runs full-screen and works offline.
